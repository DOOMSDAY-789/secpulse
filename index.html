Has this password leaked?

Your password is hashed on this device. Only the first 5 characters of the hash are sent to Have I Been Pwned, so nobody (not even them) learns the password. Nothing is saved.

Is this website safe to use?

Check a site before you sign up, log in or pay. Past leaks are looked up on this device; only the site name is sent to Mozilla's free security scanner. Nothing is saved.

Phone alerts (ntfy)

Install the free ntfy app, tap +, and subscribe to the topic below. Anyone who knows the topic name can read it and send fake alerts to it, so keep the random one and don't share it. Real alerts only list public breach and CVE news: they never ask you to log in, pay or install anything.
